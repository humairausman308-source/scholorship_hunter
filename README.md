Scholarship Hunter
Scholarship Hunter is a Streamlit web app that helps students discover scholarships tailored to their profile.
It uses LangChain + Google Gemini (Generative AI) to recommend relevant non-medical scholarships worldwide based on academic background, nationality, GPA, and achievements.

 Features
 Personalized scholarship recommendations
 Worldwide (non-medical) scholarships
 AI-powered matching using Google Gemini

 Considers:
Academic level
Field of study & specialization
GPA
Nationality & country of residence
Financial need
Extracurriculars & achievements
Chat history tracking
Styled UI with custom Streamlit CSS
